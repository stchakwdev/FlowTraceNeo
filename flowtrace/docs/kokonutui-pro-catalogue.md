# Kokonut UI Pro

> 100+ premium UI components and Next.js templates built with React, Tailwind CSS, shadcn, and Motion. Pay once, own the source forever.

- [Agents](https://kokonutui.pro/docs/agents.md): Use Kokonut UI Pro with Claude Code, Cursor, VS Code or Codex. Connect the shadcn MCP server, add your API key and a rules file, and give your agent the docs as Markdown.
